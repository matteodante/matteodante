# AGENTS.md

Shared instructions for coding agents working in this repository (the public GitHub profile of Matteo Dante).

## What this repository is

- `README.md` is the profile page: selected work, the `Writing` list and the badges.
- `assets/` holds the profile images.
- The blog articles moved on 2026-10-23 to the site repository `matteodante/portfolio-cockpit`
  (`content/blog/`, images in `public/blog/images/`, writing rules in `content/blog/AGENTS.md`). This repository's
  history keeps them up to that day. Here only the `Writing` list remains, with one line per article linking to
  `https://matteodante.it/en/blog/<slug>`.

## Writing list

- One line per published article, newest first: `[Title](https://matteodante.it/en/blog/<slug>)`, then one sentence on
  what the article is about, in the same form as the existing lines.
- Add or update the line when an article is published, retitled or renamed on the site. The slug never changes.
